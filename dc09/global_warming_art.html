Global warming through data - an artistic approach

Filippo Pilutti

2026-11-13

Objective

Starting from the NASA GISTEMP dataset, our goal is to artistically visualize the evolution of global temperatures over time. We aim to move beyond conventional data visualization techniques by creating a distinctive and visually compelling representation that combines artistic expression with statistical accuracy, while preserving the underlying data and its meaning.

Artwork generation

# number of points used to draw the curve of each blade
n_points <- 12

# define needed data, one blade of grass per monthly observation
grass <- temp |>
  mutate(
    blade_id = row_number(),
    # divide in rows, one per each decade, oldest on top
    decade = (Year %/% 10) * 10,
    row = (decade - min(decade)) / 10,
    # horizontal position within the decade (from 0 to 10 years)
    x_root = (Year - decade) + (month - 1) / 12,
    y_root = -row,
    
    # heat stress: 0 is coldest month on record, 1 warmest
    # stress = rescale(anomaly, to = c(0, 1)),
    
    # healthy blades are tall green and straight,
    # stressed blades are short red and bent
    # height = 1.1 - 0.85 * stress,
    # lean = 1.1 * stress
    
    # raw anomaly: 0 is the 1951-1980 average
    height = 0.8 - 0.35 * anomaly,
    lean = 0.7 * anomaly
  )

# bending of the blades
# t = 0 is the root, t = 1 is the tip
blades <- grass |>
  cross_join(tibble(t = seq(0, 1, length.out = n_points))) |>
  mutate(
    x = x_root + lean * t^2, # bends more towards the tip
    y = y_root + height * t, # grows steadily upwards
    width = 0.75 * (1 - 0.8 * t) # thick at the root, thin at the tip
  )

# labels for the decades
decade_labels <- grass |>
  distinct(decade, y_root)

# Legend: three sample blades drawn with the same rules
legend_y <- min(grass$y_root) - 1.9

legend_grass <- tibble(
  anomaly = c(-0.8, 0, 1.5),
  label = c(
    "-0.8 \u00B0C\ncolder than average:\ntall, green, leaning left",
    "0 \u00B0C\n1951-1980 average:\nupright",
    "+1.5 \u00B0C\nwarmer than average:\nshort, red, leaning right"
  ),
  blade_id = c(-1, -2, -3),
  x_root = c(2, 5, 8),
  y_root = legend_y
) |>
  mutate(
    # same mapping used for the real blades
    height = 0.8 - 0.35 * anomaly,
    lean = 0.7 * anomaly
  )

legend_blades <- legend_grass |>
  cross_join(tibble(t = seq(0, 1, length.out = n_points))) |>
  mutate(
    x = x_root + lean * t^2,
    y = y_root + height * t,
    # slightly thicker than real blades, to be readable
    width = 1.5 * (1 - 0.8 * t)
  )

# Artwork
artwork <- ggplot(blades) +
  geom_path(

      x = x,
      y = y,

      x = x, y = y,

    lineend = "round"

artwork

The idea behind the artwork is to visualize the change of temperature through the years as a field of grass. Each blade of grass represents a month of the dataset, and its color, length and curve represent the anomaly of that month.

The grass field is read like a page of text: each row is a decade, from the 1880s at the top to the 2020s at the bottom, and within a row the blades follow one another month by month from left to right. All three visual properties of a blade are computed directly from the raw anomaly of its month, so that zero corresponds to the 1951–1980 average. The height decreases linearly with the anomaly (height = 0.8 - 0.35 * anomaly), so colder months grow taller and warmer months stay shorter. The sideways displacement of the tip is proportional to the anomaly (lean = 0.7 * anomaly): a month at the baseline stands upright, a colder month leans to the left and a warmer month leans to the right. The color follows a gradient from dark green for the coldest months, through yellow around the baseline, to dark red for the warmest ones.

To draw a curved blade instead of a straight segment, each observation is expanded into 12 points along a parameter t that goes from 0 at the root to 1 at the tip. The vertical position grows steadily with t, while the horizontal displacement grows with t^2, so the blade starts almost vertical and bends progressively towards the tip, tracing an arc of parabola. The points of each blade are connected with geom_path(), and the line width decreases from root to tip to give the blade a tapered shape. The three blades below the grass field act as a legend: they are generated with the same formulas, using the coldest anomaly on record, the baseline and the warmest anomaly on record.

The result is a field that is tall, green and leaning one way at the top, and gradually turns short, red and flattened in the opposite direction at the bottom: the warming trend is visible as the grass withers decade after decade.
