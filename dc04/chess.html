The Elo method in chess

Filippo Pilutti

2026-10-21

Elo method was coined by the physics professor and excellent chess player Arpad Elo. In 1970, FIDE, the World Chess Federation, agreed to adopt the Elo Rating System.

The method works as follows. Suppose that players \(i\) and \(j\) match. Let \(s_{i,j}\) be the actual score of \(i\) in the match against \(j\). We have that:

  • \(s_{i,j} = 1\) if \(i\) wins;
  • \(s_{i,j} = 0\) if \(i\) loses; and
  • \(s_{i,j} = 0.5\) if there is a draw.

Notice that the actual score \(s_{j,i}\) of \(j\) in the match against \(i\) is \(1 - s_{i,j}\). Let \(\mu_{i,j}\) be the expected score of \(i\) in the match against \(j\). We have that:

\[ \begin{array}{lll} \mu_{i,j} & = & \frac{1}{1 + 10^{-(r_i - r_j) / \zeta}} = \frac{10^{r_i / \zeta}}{10^{r_i / \zeta} + 10^{r_j / \zeta}} \\\\ \end{array} \]

with \(r_i\) and \(r_j\) the ratings of \(i\) and \(j\) before the match and \(\zeta\) is a constant. Notice that the expected score \(\mu_{j,i}\) of \(j\) in the match against \(i\) is \(1 - \mu_{i,j}\).

We assume that initially all player ratings are equal to 0. When players \(i\) and \(j\) match, the new ratings \(r_i\) of \(i\) and \(r_j\) of \(j\) are modified using the following update rule:

\[ \begin{array}{lll} r_{i} & \leftarrow & r_i + \kappa (s_{i,j} - \mu_{i,j}) \\ r_j & \leftarrow & r_j + \kappa (s_{j,i} - \mu_{j,i}) \end{array} \]

where \(\kappa\) is a constant.

The Elo thesis is:

If a player performs as expected, it gains nothing. If it performs better than expected, it is rewarded, while if it performs poorer than expected, it is penalized.

Challenge 2 - Write a function that computes the player point rating (1 point for wins, 0.5 points for draws, 0 points for defeats). How are point ratings distributed? Why?

# Compute the player rating of a player, given its id
player_points <- function(id, data) {
  # Games played as White: the player gets "Score" points
  points_as_white <- sum(data$Score[data$White == id])
  # Games played as Black: the player gets "1 - Score" points
  points_as_black <- sum(1 - data$Score[data$Black == id])
  points_as_white + points_as_black
}

# Get all distinct player ids
players <- union(chess$White, chess$Black)

# Apply points function to all players

Challenge 3 - An interesting property of Elo’s ratings is that the sum of all player ratings is always 0. Formally show this property. (Hint: use the fact that \(s_{i,j} + s_{j,i}=1\) and \(\mu_{i,j} + \mu_{j,i} =1\))

Proof. All players start with a rating of 0, so initially the sum of all ratings is obviously 0. Consider then a game between players \(i\) and \(j\): only their two ratings will change after the game, and the sum will change by

\[ \kappa (s_{i,j} - \mu_{i,j}) + \kappa (s_{j,i} - \mu_{j,i}) = \kappa ((s_{i,j} + s_{j,i}) - (\mu_{i,j} + \mu_{j,i})) = \kappa (1 - 1) = 0. \] Hence every game leaves the total sum unchanged, and the sum of all ratings is always 0.

Challenge 4 - Write a function that computes the player Elo rating (set \(\zeta = 400\) and \(\kappa = 25\)) (Hint: take advantage of the 0-sum property to optimize the code). Observe its distribution: why is different from the point distribution? Verify the 0-sum property for Elo’s ratings

It’s not possible to write a function that computes the Elo of a single player, as I did with the points rating before, since Elo computation needs the current Elo of both players for every single match. So I will write a function that computes it for all the players, game by game, in chronological order.

# Elo function
elo_rating <- function(data, zeta = 400, kappa = 25) {
  
  # Create a vector with one entry per possible id
  rating <- rep(0, max(data$White, data$Black))
  
  for (k in 1:nrow(data)) {
    i <- data$White[k]
    j <- data$Black[k]
    # Expected score of white, using rating values from before the game
    mu <- 1 / (1 + 10^(-(rating[i] - rating[j]) / zeta))
    # Using zero-sum property, Black gets opposite rating change than White
    delta <- kappa * (data$Score[k] - mu)
    rating[i] <- rating[i] + delta
    rating[j] <- rating[j] - delta
  }
  
  # We keep the ids of only players that actually played
  players <- union(data$White, data$Black)
  tibble(player = players, elo = rating[players]) |>
    arrange(desc(elo))
}

Unlike the points distribution, here we have a peak on value 0, and two tails toward negative values and high positive values. This is because Elo is not cumulative: it does not accumulate while playing more. A player gains Elo points only by behaving better than predicted and loses them by doing worse.

Main characteristics:

  • There are negative values and the mean is exactly 0
  • There is a peak at around 0: many players have very few games on record, and every game barely moves their rating.
  • The tails are composed by players who played a lot of games. Only with lots of games, the rating has the time to significantly move away from 0.

Let’s verify the 0-sum property:

sum(elo$elo)
## [1] 7.638334e-13
all.equal(sum(elo$elo), 0)
## [1] TRUE

The sum is not exactly 0, but a really small number (7.638334e-13). This is due to floating-point rounding errors accumulated over 65,053 updates. Using all.equal to check for the equality returns TRUE, since it allows for a very small tolerance.

Let’s quantify the overlap between top Elo players and top points players.

# Function to measure the number of players in common between the top k players
# of the two rankings.
top_overlap <- function(k) {
  top_points <- head(point_rating$player, k)
  top_elo <- head(elo$player, k)
  length(intersect(top_points, top_elo))
}

# Check the overlap in top 10, 50, 100, 500, 1000
k <- c(10, 50, 100, 500, 1000)
tibble(
  k = k,
  overlap = sapply(k, top_overlap),

We have two very different plots.

In the points plot, the players are almost on a straight line. More games means more points, almost without exceptions.

The Elo plot looks very similar to the Points vs Elo plot, that is because we have just seen that there is basically a linear correlation between games and points. We see that who played less, has a sparse Elo above and below 0, while who played more (more than 100 games), is almost always above 0.

In conclusion, we can see that the number of played games has an effect on both ratings, but with a big difference in intensity: really strong for points rating, weak for Elo, and concentrated on the most active players. We can then conclude that Elo rating is a a more appropriate measure of relative strength of a chess player, since points rating is highly influenced by the number of played games.
